# Omar Khattab Portfolio

I built my portfolio to give visitors a clear way to explore my software projects, work experience, education, and technical skills. It brings the background behind my work together with links to the projects themselves.

[Visit my portfolio](https://www.omarkhattab.ca)

## What it does

- Present my background, projects, experience, skills, education, and contact information in one continuous page.
- Open project details with descriptions and links to related work.
- Support navigation between sections, including direct links to a section.
- Adapt the layout and navigation for desktop and mobile screens.
- Offer light and dark themes.
- Provide résumé access and links to my professional profiles.

## Design approach

I used React and TypeScript to organize the site into reusable sections and components. Shared styling and motion connect the sections while keeping the project information easy to browse.

The portfolio is a personal introduction to my work. Individual project repositories provide the source and project-specific context.
